# Fundamentos de Inteligência Artificial — Mestrado em Computação Aplicada (UEPG)

Repositório acadêmico com códigos-fonte desenvolvidos durante a disciplina de Fundamentos de Inteligência Artificial do Mestrado em Computação Aplicada da Universidade Estadual de Ponta Grossa (UEPG).

## Contexto

Os exemplos foram produzidos em atividades didáticas que envolveram integradores químicos. Imagens e materiais de terceiros podem estar sujeitos a restrições de uso; por isso, este repositório não concede direitos de redistribuição sobre esses conteúdos.

## Como utilizar

1. Consulte os arquivos-fonte disponíveis neste repositório.
2. Verifique dependências e instruções indicadas nos próprios scripts.
3. Execute os exemplos em ambiente compatível com as bibliotecas utilizadas.

## Escopo e limitações

Este é um registro de atividade acadêmica, não um produto de software mantido nem um sistema de uso clínico ou industrial. A implementação deve ser interpretada no contexto didático em que foi desenvolvida.
